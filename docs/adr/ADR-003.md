# ADR-003: Integración de plugins oficiales de Capacitor (Cámara y GPS) y compilación de APK con Android Studio

- **Estado:** Aprobado
- **Fecha:** 2026-11-21
- **Autor(es) y equipo:** Lucero San Lucas Jimy Sullivan (Proponente) — Equipo Grupo 5: Díaz Bedón Daniel Andrés, Lucero San Lucas Jimy Sullivan, Vargas Chávez Michael Jordan
- **Requisitos relacionados:** Punto 1 (aplicación móvil compilable a Android APK para entrega y defensa), R7 (capturar fotografía de cada acta desde la app, comprobar nitidez antes de aceptarla, guardar coordenadas GPS y gestionar permisos/errores), R4 (consulta de coordenadas GPS), R6 (registro de actas por el veedor).

## Contexto

Durante el escrutinio en mesa, el veedor debe capturar una fotografía legible del acta física directamente desde la app (R7), adjuntar automáticamente las coordenadas GPS del dispositivo y gestionar de forma controlada la denegación de permisos o fallos de hardware en Android. Además, el proyecto web Ionic debe empaquetarse como un instalador nativo Android (`.apk`) funcional para su despliegue en dispositivos físicos y evaluación técnica.

## Alternativas consideradas

| Alternativa | Ventajas para este caso | Desventajas / riesgos |
| :--- | :--- | :--- |
| **Opción A: Capacitor (`@capacitor/android`, `@capacitor/camera`, `@capacitor/geolocation`) + validación de nitidez + Android Studio** | Plugins oficiales mantenidos por Ionic con soporte nativo para Android; permiten restringir `CameraSource.Camera` (evitando fotos de galería), controlar resolución/compresión (`width: 1280`, `quality: 80`) antes de subir a Supabase Storage, validar nitidez localmente mediante varianza Laplaciana en Canvas HTML5 y compilar el APK instalable mediante Android Studio y Gradle. | Requiere sincronizar cada compilación web con `npx cap sync android`, declarar permisos explícitos en `AndroidManifest.xml` y configurar el SDK de Android en Android Studio. |
| **Opción B: APIs web del navegador (`getUserMedia` y `navigator.geolocation`)** | Sin dependencias nativas ni configuración de proyectos Android adicionales. | Comportamiento errático en Android WebView respecto a permisos de cámara, menor precisión GPS dentro de aulas escolares y falta de control nativo de compresión. |
| **Opción C: Apache Cordova + compilación heredada** | Compatibilidad con plugins históricos. | Mantenimiento limitado, conflictos frecuentes con versiones modernas de Android Gradle Plugin en Android Studio y tipado deficiente en TypeScript. |

## Decisión

Se adoptan los plugins oficiales de Capacitor: `@capacitor/camera` (`CameraSource.Camera`, `width: 1280`, `quality: 80`) y `@capacitor/geolocation` (`enableHighAccuracy: true`, `timeout: 10000`), integrados con un servicio `ImageQualityService` que evalúa la nitidez mediante la varianza del operador Laplaciano en escala de grises (umbral `>= 100`). Para la generación del paquete instalable, se estandariza el flujo `ionic build` -> `npx cap sync android` -> compilación de APK desde Android Studio (`Build > Build Bundle(s) / APK(s) > Build APK(s)`).

## Consecuencias

- **Beneficios:** Garantiza evidencia fotográfica nítida antes de subirla a Supabase Storage, registra latitud y longitud verificables en Firestore y permite generar el archivo APK final de manera reproducible desde Android Studio.
- **Obligaciones:** Declarar `CAMERA`, `ACCESS_COARSE_LOCATION` y `ACCESS_FINE_LOCATION` en `AndroidManifest.xml` y solicitar permisos en tiempo de ejecución.
- **Limitaciones y riesgo:** En interiores de recintos con baja señal satelital, el GPS de alta precisión puede exceder el tiempo de espera; se mitiga aplicando respaldo a precisión balanceada con mensaje informativo y botón de reintento.

## Verificación

Ejecutar `ionic build && npx cap sync android`, abrir la carpeta `android/` en Android Studio y generar `app-debug.apk`; instalar en teléfono Android y comprobar:
1. Aviso claro sin cierre inesperado al denegar permisos de cámara/GPS.
2. Rechazo automático al tomar una foto borrosa.
3. Captura nítida subida a Supabase Storage con coordenadas GPS guardadas en Firebase Firestore.
